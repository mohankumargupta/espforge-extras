# wokwi/

Viewer payloads only. Directories hold:

- `diagram.json`
- `firmware.bin`
- `chip.json` (for chip examples, with `name` parameter renamed to match the example, e.g. `i2cexample`)

Generated by `just build [example]` and read by the Wokwi experimental viewer.

Compiled chip WASM artifacts (`chip.wasm`) live in `../espforge-examples-generated/<example>/`. The live viewer resolves a chip through `diagram.json` → `dependencies` (e.g. `chip-i2cexample`) → the GitHub release asset `chip.zip`.
