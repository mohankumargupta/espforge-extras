# wokwi/

Viewer payloads only. Each directory holds exactly:

- `diagram.json`
- `firmware.bin`

Generated by `just build [example]` and read by the Wokwi experimental viewer.

Chip artifacts (`chip.json`, `chip.wasm`) and `wokwi.toml` live in
`../espforge-examples-generated/<example>/` and are never copied here — the live viewer
resolves a chip through `diagram.json` → `dependencies` → the GitHub release asset
`chip.zip` (`chip-<example>-0.0.N`).
